# Media untuk README

Taruh file screenshot/GIF di folder ini dengan nama berikut, lalu buka komentar blok
gambar di `README.md` (English) dan `README.id.md` (Bahasa Indonesia).

| Nama file | Isi yang disarankan |
|---|---|
| `dashboard.png` | Halaman Homepage: daftar subject/session dan kartu statistik |
| `analysis.png` | Wizard Analysis dengan stepper 6 tahap terlihat |
| `report.png` | Halaman Report: video + grafik fase STANCE/SWING + tabel parameter |
| `monitoring.png` | Halaman Monitoring: grafik tren antar session |
| `demo.gif` | Rekaman layar singkat: video berjalan → skeleton overlay → plot fase gait |

Tips:

- Resolusi lebar 1200–1600 px, ukuran file < 2 MB per gambar.
- GIF demo idealnya 10–20 detik, 10–15 fps, dan < 8 MB agar cepat dimuat di GitHub.
- Jangan menampilkan data pribadi subjek (wajah/nama) pada screenshot.
